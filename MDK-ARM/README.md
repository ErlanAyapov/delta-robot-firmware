# Кіші Дельта Робот

Бұл жоба кіші дельта роботты басқаруға арналған. Роботтың негізгі сипаттамалары:  
- **3 консевигі бар**: Роботтың үш қозғалмалы осі бар.  
- **RS485 арқылы басқару**: Командалар RS485 интерфейсі арқылы жіберіледі.  
- **100 сегмент**: Робот 100 сегментке дейінгі қозғалыс траекториясын орындай алады.  

## Қолдану

1. RS485 интерфейсін конфигурациялау.  
2. Командаларды жіберу үшін арнайы протоколды пайдалану.  
3. Қозғалыс траекториясын алдын ала жоспарлау.  

## Файлдар

- **main.c**: Негізгі басқару логикасы.  
- **rs485.c**: RS485 интерфейсі үшін драйвер.  
- **trajectory.c**: Қозғалыс траекториясын есептеу.  

## Лицензия

Бұл жоба ашық бастапқы кодты және тек білім беру мақсатында қолданылады.
